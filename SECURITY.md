# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability or potential threat in the Urban Air Quality Assistant:

1. **Do not open a public issue.**
2. Report the vulnerability privately via GitHub Security Advisories or contact the repository maintainers directly.
3. Please include:
   - A description of the issue and potential impact.
   - Minimal steps or proof-of-concept to reproduce the behavior.
   - Suggested mitigations if known.

We aim to acknowledge reports within 48 hours and provide a fix or advisory promptly.
